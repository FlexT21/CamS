# Servidor CamS

Carga las fotografías de `users/<nombre>/`, reconoce un único rostro por solicitud WebSocket y publica reconocimientos en MQTT. No calcula cruces ni envía comandos al Arduino: esas funciones corresponden al cliente.

Instalación y ejecución: [README principal](../../README.md). Funcionamiento: [SYSTEM.md](../../SYSTEM.md). Verificación: [VERIFICACION.md](../../VERIFICACION.md).
